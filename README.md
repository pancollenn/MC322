## 📜 Descrição

Implementação do jogo de tabuleiro Monopoly desenvolvida em Java como projeto para a disciplina MC322 - Programação Orientada a Objetos da Universidade Estadual de Campinas (Unicamp). O projeto visa aplicar os conceitos de OOP para simular as regras e a jogabilidade do Monopoly clássico em um ambiente digital (via console).

## ✨ Funcionalidades Implementadas

*   🎲 **Rolagem de Dados:** Simulação da rolagem de dois dados para movimentação.
*   ♟️ **Movimentação de Jogadores:** Peões se movem pelo tabuleiro de acordo com os dados.
*   🏠 **Gerenciamento de Propriedades:** Compra, venda, hipoteca de títulos de propriedade.
*   💰 **Cobrança de Aluguel:** Jogadores pagam aluguel ao parar em propriedades de outros.
*   🏦 **Construção:** Possibilidade de construir casas e hotéis.
*   ❓ **Cartas Sorte:** Retirada e execução de ações das cartas.
*   💸 **Falência:** Jogador é eliminado ao não conseguir pagar suas dívidas.
*   🏆 **Condição de Vitória:** O último jogador restante "não falido" vence o jogo.
*   👥 **Múltiplos Jogadores:** Suporte para múltiplos jogadores e registro de conta.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Java 
*   **Paradigma:** Programação Orientada a Objetos (OOP)
